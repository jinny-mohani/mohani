# 실제 앱 화면 → 피그마 옮기기 (Nov 18)

이 클라우드 환경에서는 피그마의 HTML 가져오기·업로드 주소가 막혀 있어서, 화면을 직접 읽어 피그마 레이어로 다시 그려요.

1. `capture.js` (tests/screens.js + `dump.js`) — 가짜 데이터로 앱을 띄워 화면마다 독립 HTML 저장
2. `run-extract.js` + `extract.js` — 화면을 상자·글자·아이콘·이미지 트리(JSON)로 읽기. 반복 요소(버튼·칩·탭바 등)는 컴포넌트로 표시
3. `build.js` — 트리 정리, 컴포넌트 정의·이미지 목록 분리
4. `gen.js` — use_figma로 보낼 코드 만들기 (데이터는 deflate 압축 → `inflate.js`로 풀기, 그리기는 `runtime.js`)

피그마: 페이지 "실제 화면 (11.18)" — 섹션 "실제 앱 화면"(46화면), "컴포넌트"(18종 · 변형 45개)
