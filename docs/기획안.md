# 함께 가요! 기획안

Nov 14, 2026 · @허지니

## 개요

\*\*함께 가요!\*\*는 친구들과 여행 정보를 모바일에서 함께 보고, 함께 고치는 웹앱입니다. 로그인 없이 링크 하나로 들어오고, 모든 내용은 구글 시트 하나에 저장됩니다.

| 항목 | 내용 |
| --- | --- |
| 앱 이름 | 함께 가요! |
| 사용자 | 여행을 같이 가는 친구들 (인원 가변) |
| 기준 여행 | 2박 3일 (날짜·기간·인원은 여행마다 설정) |
| 사용 시점 | 여행 전: 준비 체크 / 여행 중: 일정·장소 확인 |
| 플랫폼 | 모바일 웹앱(PWA) — 홈 화면에 추가해서 앱처럼 사용 |

## 제작 배경

기존 도구로는 ‘날짜별 일정을 친구와 모바일에서 같이 보고 고치기’가 안 됩니다.

| 도구 | 불편한 점 | 함께 가요!의 해결 |
| --- | --- | --- |
| 노션 | 모바일에서 화면이 잘림, 타인과 편집 공유 시 멤버십 결제 필요 | 모바일 전용 화면, 링크만 있으면 무료로 편집 |
| 구글 지도 | 장소는 저장되지만 날짜별 일정 공유 불가 | 일별 코스 + 장소 목록을 한 곳에서, 위치는 구글 지도로 연결 |

## 핵심 원칙

1. **로그인 없음** — 여행별 초대 링크로 접속합니다. 여행 코드는 휴대폰에 기억되어 다음부터는 앱만 열면 됩니다. 처음 들어올 때 개설자가 등록한 멤버 프로필 중에서 나를 고르면, 누가 쓴 글인지 표시됩니다.
2. **모두가 편집자** — 여행 멤버라면 누구나 모든 정보(예약·물품·일정·장소·친구들)를 글쓰기·수정·삭제할 수 있습니다. 다른 사람이 쓴 글도 고칠 수 있고, 권한 구분은 두지 않습니다. 여러 명이 동시에 접속해도 되고, 다른 사람의 변경은 자동으로 반영됩니다.
3. **구글 시트가 원본** — 모든 데이터는 시트 하나에 저장됩니다. PC에서는 시트에 한 번에 입력하고, 모바일에서는 앱으로 입력합니다. 어느 쪽에서 쓰든 같은 내용이 보입니다.
4. **여행 설정은 바꿀 수 있음** — 날짜·기간·인원을 수정하면 일별 코스 탭 수와 멤버 목록이 따라 바뀝니다.
5. **여행 중에도 보기** — 마지막으로 불러온 내용을 휴대폰에 저장해 두어, 해외나 지하처럼 인터넷이 약해도 읽을 수 있습니다.

## 기능 상세

모든 항목은 멤버 누구나 추가·수정·삭제할 수 있고, 마지막으로 고친 사람이 표시됩니다. 지운 항목은 최근 삭제(03-7)에서 누구나 되살릴 수 있습니다. 같은 종류의 새로 쓰기와 수정은 한 화면을 같이 씁니다.

### 0. 여행 만들기와 참여

1. **개설자**가 여행 이름·목적지·날짜·대표 이미지와 멤버(이름·관계)를 등록하면 초대 링크가 만들어집니다. 카카오톡으로 보내거나 링크를 복사합니다.
2. **친구**는 초대 링크로 들어와 멤버 프로필 카드(사진·이름·관계) 중 자신을 고르고 입장합니다. 다시 누르면 선택이 취소됩니다.
3. 목록에 내가 없으면 '목록에 내가 없어요'를 눌러 멤버를 추가합니다.
4. 고른 프로필은 여행별로 휴대폰에 기억되고, 다음부터는 바로 홈이 열립니다.
5. 여행 정보는 홈의 설정 아이콘에서 누구나 고칩니다. 날짜를 줄이면 빠진 Day의 일정은 마지막 Day로 옮겨집니다.

### 2. 예약

- **목록**: 전체 · 항공권 · 숙소 · 기타 칩으로 걸러 봅니다. '전체'에서 + 를 누르면 종류부터 고릅니다.
- **상태 라벨**: 예약 전(시계) · 예약 완료(체크) · 보류(일시정지). 색 없이 아이콘·테두리로 구분합니다.
- **상세**: 수정 버튼은 아래, 삭제는 ⋯ 메뉴. 작성 화면의 추가 정보는 접혀 있다가 필요할 때 펼칩니다.

| 종류 | 기본 항목 | 추가 정보 (태그로 표시) |
| --- | --- | --- |
| 항공권 | 구분(가는/오는 편), 출발·도착 공항(코드 · 이름 · 터미널, 예: ICN 인천 · T1), 날짜·시간, 소요 시간, 항공사, 상태. 예약번호·담당은 상세에서만. 카드는 정사각형 사진 위에 흰 정보 패널 | 항공편 · 기종 · 좌석(패널 안 3칸), 예약처, 메모(목록에서 2줄까지) |

### 3. 체크 리스트 (11.22 공통 / 개인으로 다시 정리)

여행 준비물 중 공통 일은 노션 같은 곳에 함께 적지만, 개인 짐은 따로 메모하다 빼먹기 쉽다는 사용자 경험에서 출발했어요. 그래서 **누구의 일인지**로 나눕니다.

| 구분 | 예시 | 보이는 사람 | 담당 · 체크 | 묶음 |
| --- | --- | --- | --- | --- |
| 공통 | 항공권·숙박·버스투어 예약 | 친구 모두 | 멤버 1명(한 명이 하면 끝) 또는 '각자'(멤버마다 따로 체크, 이름 표시 없음) | 없음 ('함께 할 일' 한 목록) |
| 개인 | 원피스 3벌, 고데기, 유심 사기 | 쓴 사람만 | 항상 나 (이름 표시 없음) | 내 짐 · 내 할 일 |

- 전체 화면(03-3): 위에 [공통] [개인] 탭. 개인 탭에는 "나만 보는 목록이에요 · 친구들 화면에는 안 보여요" 안내.
- 추가·수정(03-6): 구분(공통/개인) → 개인이면 종류(짐/할 일), 공통이면 담당(각자/멤버). 기한은 쓰지 않음.
- 홈: 카드 3개 — 공통(체크박스 3개), 내 짐(태그, 최대 5개), 내 할 일(체크박스 3개). 개인 카드 제목 옆에 자물쇠.
- 예전 구분(여행 전 할 일·짐 꾸리기·공항에서 할 일)으로 적힌 항목은 모두 공통으로 보여요.
- **나만 보기 수준 (사용자 결정 A)**: 개인 항목도 구글 시트에 저장하고 앱 화면에서만 숨겨요. 폰을 바꿔도 남는 대신, 시트 주인이나 내 프로필을 골라 들어온 사람은 볼 수 있어요. 그래서 화면 문구는 "비밀"이 아니라 "친구들 화면에는 안 보여요"로 씁니다. 앱마켓 출시(2차) 때 로그인을 붙이면 서버에서 걸러 진짜 나만 보기로 올립니다.

### 4. 일정

| 항목 | 내용 |

### 5. 장소

- 카테고리는 음식점 · 즐길거리 · 쇼핑 · 디저트이고, 모든 카테고리가 같은 등록 화면을 씁니다.
- 입력 항목: 장소 이름, 사진(최대 3장, 가로 6:5), 구글 지도 링크, 정확한 주소(층·랜드마크까지), 운영시간, 브레이크타임(있음/없음), 메모
- 상세: 도로명 + 지번·랜드마크, 지도에서 보기·주소 복사. '일정에 추가'를 누르면 장소가 채워진 일정 추가 화면이 열립니다.

  전체 탭 (11.28): 카테고리별 제목(이름 + 초록 개수 + ›) 아래 240 폭 카드를 가로 스와이프로 최대 5개. 카드는 사진 240×180(모서리 15, 오른쪽 아래 지도 버튼) 아래에 이름 · 메모 1줄 · 운영시간 (홈 '기타 예약'과 같은 모양). 제목을 누르면 해당 카테고리 탭으로.
  카테고리 탭 (11.28): 예약 '전체'와 같은 줄 목록 — 왼쪽 128 사진(지도 버튼) + 이름 · 메모 1줄 · 운영시간.

  상세 화면: 사진이 위를 채우고 흰 시트가 겹쳐 올라옴. 운영시간 · 브레이크타임 · 웨이팅을 한 줄 박스로, 아래에 사진 3장.

### 6. 친구들

- **목록**: 프로필, 이름, 관계, 소개(2줄까지, 넘치면 ∨로 펼침). 맨 아래 '+ 멤버 추가'.
- **내 프로필 수정**: 이름 · 관계 · 소개. 사진의 연필을 누르면 프로필 사진 선택 시트가 열립니다. 직접 등록 + 캐릭터 6종, 다른 친구가 쓰는 캐릭터는 'OO 사용 중'으로 잠겨 고를 수 없습니다 (피그마 11-2 기준으로 변경, Nov 16).
- **멤버 추가**: 이름, 관계, 소개 한 줄(선택), 프로필(선택). 처음 설정 이후에는 누구나 추가할 수 있습니다.
- **소개**는 최대 3줄 (목록에서는 2줄까지 보이고 ∨로 펼침).

## 데이터 구조 (구글 시트)

구글 시트 파일 1개에 모든 여행을 담고, 기능 1개 = 시트 탭 1개로 나눕니다. 모든 탭에 여행id 컬럼을 두어 어느 여행의 항목인지 구분합니다. 탭마다 첫 줄은 컬럼 이름이고, 한 줄이 항목 하나입니다. 그래서 PC에서 시트에 직접 줄을 추가해도 앱에 그대로 나타납니다.

| 시트 탭 | 컬럼 |
| --- | --- |
| 여행정보 | 여행id, 여행명, 시작일, 종료일, 목적지, 대표 이미지, 초대코드, 개설자 |
| 멤버 | id, 여행id, 이름, 관계, 소개, 개설자 여부, 프로필(캐릭터 번호 또는 사진URL), 순서 |
| 예약정보 | **공통**: id, 여행id, 종류(항공권/숙소/기타), 예약명, 시작 일시, 종료 일시, 장소, 지도링크, 예약번호, 상태(예약 전/예약 완료/보류), 담당, 사진URL, 메모, 예약처, 비용, 순서 · **항공권**: 구분(가는/오는 편), 출발 공항, 출발 터미널, 도착 공항, 도착 터미널, 소요 시간, 항공사, 항공편, 기종, 좌석 · **숙소**: 객실 형태, 방 크기, 체크인 시간 · **기타**: 세부 종류(렌터카/투어/체험/입장권/직접 입력), 인원 |
| 체크 리스트 | id, 여행id, 할 일, 구분(공통/개인 짐/개인 할 일 — 예전 값은 공통으로 봄), 담당(각자/멤버id, 개인은 쓴 사람 id), 기한(안 씀), 완료한 멤버(멤버id 쉼표 구분), 순서 |
| 장소 | id, 여행id, 카테고리, 장소이름, 사진URL(쉼표 구분, 최대 3장), 지도링크, 정확한 주소, 운영시간, 브레이크타임, 웨이팅, 메모, 순서, 보조제목·전화번호·주차정보(11.21 추가, 모두 선택) |
| 일정 | id, 여행id, Day, 시간(선택), 장소id(장소 또는 숙소·기타 예약의 id — 11.22), 장소 직접 입력, 이동수단, 메모, 순서 |

여행정보를 뺀 모든 탭에는 여행id가 들어갑니다. 메모·소개 칸은 줄바꿈 포함 최대 5줄입니다. 예약정보는 탭 하나에 두고, 종류별 칸은 해당 종류만 채웁니다.

모든 탭 끝에는 **수정자·수정시간** 컬럼을 둡니다. 동시 편집과 ‘누가 고쳤는지’ 표시에 씁니다.

삭제는 줄을 지우지 않고 **삭제됨 · 삭제자 · 삭제시간** 컬럼에 표시만 합니다.

| 상황 | 시트에서 | 앱에서 |
| --- | --- | --- |
| 삭제 | 삭제됨 = TRUE, 삭제자·삭제시간 기록 | 목록에서 숨김, ‘되돌리기’ 알림 몇 초 표시 |
| 복구 | 삭제됨 = FALSE | ‘최근 삭제’ 목록에서 누구나 되살리기 |
| 완전 삭제 | 여행이 끝난 뒤 시트에서 직접 줄 삭제 | 앱에서는 하지 않음 |

권한 구분 없이 누구나 지울 수 있으므로, 실수로 지워도 항상 되돌릴 수 있게 하는 장치입니다.

## 기술 구성과 고려사항

구글 시트를 데이터베이스처럼 쓰고, 그 위에 모바일 화면만 올리는 구조입니다. 서버를 따로 두지 않아 비용이 들지 않습니다.

| 구성 | 선택 | 이유 |
| --- | --- | --- |
| 앱 형태 | PWA(웹앱) | 앱스토어 심사 없이 링크로 공유, 홈 화면에 추가하면 앱처럼 실행 |
| 저장소 | 구글 시트 | 무료, PC에서 바로 편집 가능, 데이터가 눈에 보임 |
| 시트 연결 | Google Apps Script(시트에 붙는 작은 API) | 로그인 없이 앱이 시트를 읽고 쓸 수 있음 |
| 배포 | Vercel 또는 GitHub Pages | 무료, Claude Code에서 바로 배포 |
| 제작 도구 | Claude Code | 여러 파일 관리, 실행·수정·배포까지 한 곳에서 |

**고려할 점**

- **동시 편집 충돌**: 두 사람이 같은 항목을 동시에 고치면, 저장할 때 수정시간을 비교해 ‘○○님이 먼저 수정했어요. 덮어쓸까요?’를 보여줍니다. 항목(행) 단위로 저장해 다른 항목에는 영향이 없게 합니다.
- **자동 반영 주기**: 실시간 동기화 대신 화면을 볼 때 30초마다, 또는 화면을 아래로 당길 때 새로 불러옵니다(아래 ‘동기화 규칙’). 친구 3\~5명 규모에는 충분합니다.
- **링크 보안**: 로그인이 없으니 링크를 아는 사람은 누구나 편집할 수 있습니다. 추측하기 어려운 여행 코드를 링크에 넣고, 여권번호 같은 민감한 정보는 저장하지 않습니다.
- **사진 업로드**: 구글 시트는 사진 파일을 직접 담기 어렵습니다. 휴대폰 사진을 구글 드라이브 폴더에 올리고 시트에는 파일 주소만 저장합니다. 업로드는 Apps Script가 처리합니다.

**재접속**

처음 초대 링크를 열 때 여행 코드와 고른 멤버를 휴대폰(브라우저 저장소)에 저장합니다. 앱을 닫았다 다시 열면 저장된 코드로 여행 목록을 바로 보여줍니다. 저장소는 브라우저마다 따로라서 아래 경우엔 기억이 비어 보입니다.

| 상황 | 이유 |
| --- | --- |
| 카톡에서 열었다가 사파리·크롬으로 열음 | 카톡 내장 브라우저와 저장 공간이 다름 |
| 아이폰에서 사파리 사용 후 홈 화면에 추가 | iOS는 홈 화면 앱과 사파리 저장 공간을 나눔 |
| 브라우저 기록 삭제, 휴대폰 변경 | 저장된 값이 지워짐 |

어느 경우든 초대 링크를 다시 누르면 복구되고, 데이터는 시트에 남아 있습니다. 이를 위해 세 가지를 넣습니다.

- **홈 화면 추가 안내**: 첫 진입 때 안내하고, 홈 화면 아이콘이 초대 링크 주소로 열리게 해 아이폰에서도 이어짐
- **빈 화면 안내**: 저장된 여행이 없으면 ‘받았던 초대 링크를 다시 눌러 주세요. 링크가 없다면 여행을 만든 친구에게 받아 주세요’ (초기 버전은 초대 링크로만 입장)
- **초대 링크 복사 버튼**: 멤버 누구나 단톡방에 링크를 다시 보낼 수 있게

**동기화 규칙**

구글 시트는 변경을 앱에 알려주지 않아서, 앱이 주기적으로 물어봅니다(폴링). 요청이 느리고 횟수 제한이 있어 아래 규칙으로 요청을 아낍니다.

| 상황 | 규칙 |
| --- | --- |
| 반영 주기 | 화면을 보고 있을 때만 30초마다 + 당겨서 새로고침 |
| 앱을 내렸을 때 | 요청 멈춤, 다시 열면 즉시 1회 불러오기 |
| 입력 중일 때 | 입력 중인 항목은 새로고침에서 제외, 저장 후 반영 |
| 같은 항목 동시 수정 | 저장 시 수정시간 비교 → ‘○○님이 먼저 수정했어요. 덮어쓸까요?’ |
| 내가 저장할 때 | 화면에 먼저 반영, 저장은 뒤에서. 실패하면 ‘저장 안 됨’ 표시 |
| 불러오는 범위 | 1차는 여행 전체, 느려지면 바뀐 것만 |
| 사진 | 한 번 받은 사진은 휴대폰에 저장해 재사용 |

변경 알림(누가 무엇을 바꿨는지 표시)은 넣지 않습니다.

### 고민 중: 장소 입력을 쉽게 (11.21, 아직 결정 안 함)
문제: 써 보니 항목은 짧지만 많아서 장소 하나 입력하면 지침. 정보가 다 저장돼 있으면 여행지에서는 편함.
- **캡처 읽기**: 지도 앱 캡처 → 글자 읽어 자동 입력. AI(정확, 장당 1~2원) 또는 구글 드라이브 OCR(무료, 칸 나누기 부정확). 나라·지도 앱 상관없음
- **장소 검색 자동 입력**: 이름 검색 → 고르면 자동 입력. 해외는 구글 장소 API만 쓸 만함(카드 등록, 무료 한도 확인 필요). 카카오·네이버는 국내 위주
- **엑셀 업로드**: 입력량이 그대로라 비추천
- 입력 간소화(이름+링크만)는 "그냥 캡처해 두는 게 편하다"는 의견으로 보류
- 어떤 방법이든 API 키는 Apps Script에 두고, 외부로 보내는 정보는 개인정보처리방침에 적기

### 2차 작업: 앱마켓 출시 (11.21 결정, 아직 시작 안 함)
목적: 친구들이 당장 여행 갈 일이 없으니, 앱마켓에 올려 더 많은 사람에게서 테스트 의견을 빨리 모으기.
- **안드로이드(구글 플레이) 먼저**: PWA를 TWA로 감싸서 올림(PWABuilder). 개발자 계정 $25(1회), 개인 계정은 테스터 12명 × 14일 비공개 테스트 필요
- **아이폰은 보류**: 연 $99 + Mac 필요, 웹 감싸기 앱은 심사(4.2 최소 기능)에서 자주 거절 → 당분간 '홈 화면에 추가'로 사용
- **필요한 준비**: 개인정보처리방침 페이지, 스토어 이미지(아이콘 512 ✅, 소개 이미지 1024×500, 화면 캡처), 앱 데이터 삭제 방법 안내
- **주소**: 앱 연결 확인 파일(`.well-known/assetlinks.json`)은 도메인 맨 위에 있어야 해서 지금 주소(github.io/mohani)로는 불가 → 나만의 도메인 연결 필요
- **결정할 것**: 데이터 저장소. 지금은 개인 구글 시트 + Apps Script라 ①모르는 사람 정보가 개인 드라이브에 쌓이고 ②무료 사용량 한도가 있음. 지인 테스트용(지금 구조 유지)인지, 공개 앱(Firebase 등으로 이전)인지 정해야 함
- **로그인 (11.22 논의, 화면 테스트 뒤 자세히 의논)**: 초대 코드 진입이 불편 → 구글·카카오 로그인으로. 감정일기 앱과 같은 **Supabase**를 쓰는 방향(카카오 로그인 기본 지원, 무료 구간 넉넉). 여행 멤버 명단에 계정을 연결해 묶고, 처음 묶을 때만 초대 링크 사용. 같이 챙길 것: 아이폰 출시 시 애플 로그인, 앱 안 계정 삭제, 개인정보처리방침, 체크 리스트 개인 항목을 서버에서 걸러 진짜 나만 보기로
