# 구글 시트 + Apps Script 설정 안내

앱의 데이터를 담을 구글 시트를 만들고, 앱이 시트를 읽고 쓸 수 있게 **웹 앱 주소**를 만드는 과정이에요. 15분 정도 걸려요.

> **왜 이렇게 하나요?** 앱(휴대폰)은 구글 시트에 직접 쓸 수 없어요. 그래서 시트에 작은 프로그램(Apps Script)을 붙이고, 그 프로그램이 앱의 요청을 받아 대신 시트를 읽고 써요. 이 프로그램을 '웹 앱'으로 배포하면 주소가 하나 생기고, 앱은 그 주소로 요청을 보내요.

## 0. 준비: 개인 구글 계정

**회사 계정 말고 개인 Gmail 계정**으로 진행해 주세요.
회사(Workspace) 계정은 '링크가 있는 누구나 보기' 공유나 외부 접속이 막혀 있는 경우가 많아서, 친구들이 사진을 못 보거나 앱이 접속하지 못할 수 있어요.

## 1. 시트 만들기

1. 개인 계정으로 로그인한 브라우저에서 [sheets.new](https://sheets.new) 를 열어요.
2. 왼쪽 위 제목을 `함께 가요! 데이터`로 바꿔요.

## 2. 코드 붙여 넣기

1. 메뉴 **확장 프로그램 → Apps Script** 를 눌러요. 새 탭에 편집기가 열려요.
2. 왼쪽 위 프로젝트 이름(제목 없는 프로젝트)을 `함께 가요! API`로 바꿔요.
3. `Code.gs`에 들어 있는 기본 코드를 **전부 지우고**, 저장소의 [`apps-script/Code.gs`](../apps-script/Code.gs) 내용을 **전부 복사해서 붙여 넣어요**.
4. 💾 저장 아이콘(또는 `Ctrl/Cmd + S`)을 눌러요.

## 3. setup 실행 (탭 자동 생성)

1. 편집기 위쪽, ▶ 실행 버튼 옆 드롭다운에서 **`setup`** 을 고르고 **▶ 실행**을 눌러요.
2. 처음 한 번은 권한을 물어봐요.
   - **권한 검토** → 내 계정 선택
   - "Google에서 확인하지 않은 앱" 화면이 나오면 → 왼쪽 아래 **고급** → **함께 가요! API(으)로 이동(안전하지 않음)** → **허용**
   - 이 경고는 *내가 직접 만든 스크립트라서 구글 심사를 받지 않았다*는 뜻이에요. 코드는 내 시트와 내 드라이브의 사진 폴더에만 접근해요.
3. 아래 **실행 로그**에 `샘플 여행 초대코드: xxxx` 와 `설정 완료!`가 보이면 성공이에요.
4. 시트 탭으로 돌아가면 아래쪽에 탭 6개가 생겨 있어요: 여행정보 · 멤버 · 예약정보 · 체크 리스트 · 장소 · 일정.

## 4. 웹 앱으로 배포 (주소 만들기)

1. 편집기 오른쪽 위 **배포 → 새 배포**
2. '유형 선택' 옆 ⚙️ 톱니 → **웹 앱**
3. 아래처럼 설정해요.

   | 칸 | 선택 | 이유 |
   | --- | --- | --- |
   | 설명 | `v1` | 나중에 버전 구분용 |
   | 다음 사용자 인증 정보로 실행 | **나** | 친구들이 로그인하지 않아도, 내 권한으로 시트에 써요 |
   | 액세스 권한이 있는 사용자 | **모든 사용자** | 로그인 없이 링크로 쓰는 앱이라서 |

4. **배포** → 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사해요.

## 5. 잘 되는지 확인

브라우저 주소창에 아래 주소를 넣어 보세요. (`웹앱주소`는 복사한 URL)

```text
웹앱주소?action=ping
```

`{"ok":true, "message":"함께 가요! 연결 성공" …}` 이 보이면 성공이에요.

샘플 여행도 불러와 보세요. (`초대코드`는 3단계 로그나 여행정보 탭의 '초대코드' 칸)

```text
웹앱주소?action=load&code=초대코드
```

## 6. 저에게 알려 주세요

**웹 앱 URL** 을 채팅으로 보내 주시면 다음 단계(앱 뼈대)에 연결할게요.
웹 앱 URL은 앱 코드 안에 들어가서 공개돼도 괜찮아요. 초대코드가 없으면 여행 내용은 읽을 수 없게 만들어 두었어요.

## 알아 두면 좋은 것

### 코드를 고친 뒤에는 '새 버전'으로 배포

`Code.gs`를 바꾸면 **배포 → 배포 관리 → ✏️ 연필 → 버전: 새 버전 → 배포** 를 눌러요.
'새 배포'를 누르면 주소가 바뀌어서 앱과 연결이 끊겨요. '배포 관리'로 하면 주소는 그대로예요.

### PC에서 시트에 직접 입력할 때

| 칸 | 규칙 |
| --- | --- |
| id | 비워 두면 앱이 처음 읽을 때 자동으로 채워요 |
| 여행id | **꼭 채우기.** 여행정보 탭의 '여행id'(예: `t_ab12cd34`)를 복사해 넣어요. 비어 있으면 어느 여행인지 몰라 앱에 안 보여요 |
| 날짜 | `2026-12-19`, 날짜+시간은 `2026-12-19T14:30` 처럼 |
| 삭제 | 줄을 지우지 말고 **삭제됨** 체크. 여행이 끝난 뒤에만 줄을 지워요 |
| 담당(체크 리스트) | `각자` 또는 멤버 탭의 id |
| 완료한 멤버 | 멤버 id를 쉼표로 (`m_aaa,m_bbb`) |
| 사진URL | 여러 장은 쉼표로 |
| 순서 | 1, 2, 3… 작은 숫자가 위 |

- 모든 칸은 '글자' 형식이에요. 시트가 `12/19`를 날짜로 멋대로 바꾸지 않게 하려는 거예요.
- 컬럼 순서는 바꿔도 되지만 **첫 줄의 컬럼 이름은 바꾸지 마세요.** 앱이 이름으로 칸을 찾아요.
- 컬럼이 빠졌거나 탭을 실수로 지웠다면 `setup`을 다시 실행하면 돼요. 있는 데이터는 건드리지 않아요.

### 시트 공유

친구들에게 시트를 공유할 필요는 없어요(앱은 웹 앱 주소로 접속). PC에서 같이 입력할 친구만 시트의 **공유** 버튼으로 편집자로 초대하세요.

### 사진

앱에서 올린 사진은 내 구글 드라이브의 `함께 가요! 사진/여행id` 폴더에 저장되고, '링크가 있는 사용자 보기'로 공유돼요.
