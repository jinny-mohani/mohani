# 앱 배포 안내 (GitHub Pages)

앱 파일을 GitHub Pages에 올려서 **휴대폰에서 열 수 있는 주소**를 만드는 과정이에요. 5분이면 돼요. 처음 한 번만 하면 되고, 그 뒤로는 제가 푸시할 때마다 자동으로 반영돼요.

> **왜 GitHub Pages인가요?** 저장소가 공개(public)라서 무료이고, 앱 파일을 그대로 올리기만 하면 돼요. 따로 서버를 빌리거나 설정할 필요가 없어요.

## 1. Pages 켜기

1. 브라우저에서 저장소를 열어요: https://github.com/jinny-mohani/mohani
2. 위쪽 메뉴 **Settings**(⚙️) → 왼쪽 메뉴 **Pages**
3. **Build and deployment** 에서
   - Source: **Deploy from a branch**
   - Branch: **`claude/serene-hawking-ncajd5`** 선택, 옆 폴더는 **`/ (root)`**
   - **Save**
4. 1~2분 기다린 뒤 새로고침하면 위쪽에 **Your site is live at https://jinny-mohani.github.io/mohani/** 가 보여요.

> 지금은 작업 브랜치(`claude/…`)에서 바로 배포해요. 나중에 main 브랜치로 합치면 Branch를 `main`으로 바꾸면 돼요.

## 2. 휴대폰에서 열기

초대 링크는 **앱 주소 + `?t=초대코드`** 예요. 샘플 여행으로 열어 보세요.

```text
https://jinny-mohani.github.io/mohani/?t=초대코드
```

`초대코드` 자리에 여행정보 탭 G2 값을 넣어요. 이 링크를 카톡 '나와의 채팅'으로 보내서 휴대폰에서 누르면 편해요.

## 3. 홈 화면에 추가

| 휴대폰 | 방법 |
| --- | --- |
| 아이폰 | **사파리**로 열기 → 아래 공유 버튼(□↑) → **홈 화면에 추가** |
| 안드로이드 | **크롬**으로 열기 → 오른쪽 위 ⋮ → **홈 화면에 추가** (또는 앱 설치) |

- 카톡에서 링크를 누르면 카톡 안 브라우저로 열려요. 오른쪽 아래(아이폰) / 오른쪽 위 ⋮(안드로이드)의 **다른 브라우저로 열기**를 눌러 사파리·크롬으로 연 뒤 추가해 주세요.
- 아이폰은 꼭 **초대 링크로 연 화면에서** 추가해 주세요. 아이폰은 그때 주소를 그대로 아이콘에 저장해서, 아이콘을 눌렀을 때 바로 그 여행이 열려요.

## 4. 확인할 것

- [ ] 홈에 '샘플 여행', 오사카, 12.19 (토) 출발 · 2박 3일, 멤버 이름이 보여요
- [ ] 하단 탭 5개를 누르면 화면이 바뀌고, 고른 탭은 아이콘이 꽉 찬 모양이 돼요
- [ ] 예약 탭 **+** → 아래에서 시트가 올라와요 → 항공권 → 전체 화면 팝업이 열려요 → ✕ 또는 뒤로 가기로 닫혀요
- [ ] 시트에서 예약정보 탭에 줄을 하나 추가하면(여행id 꼭 넣기) 30초 안에 앱에 나타나요
- [ ] 홈 화면 아이콘으로 열면 주소창 없이 앱처럼 열려요
- [ ] 비행기 모드로 열면 위에 '보기만 가능' 띠가 보이고 내용은 그대로 보여요

## 앱이 안 바뀌어 보일 때

휴대폰이 예전 파일을 기억하고 있을 수 있어요. 앱을 완전히 닫았다가 다시 열면 새 파일을 받아요. 그래도 그대로면 1~2분 뒤(GitHub이 반영하는 시간) 다시 열어 보세요.
