# 2023 피그마 시안 검토 요약

- 원본: 피그마 파일 `연산게임_v2.0 (2023.01)`, 섹션 `연산게임` (node 3405:5155)
- 보드: 로그인 과정 / 문제풀이 과정 / 우주 맵 구성 / 기타 페이지 / SNS 공유
- 모든 화면이 360×640 고정

## 가져갈 것
- 흐름: 과정 선택 → 난이도 맵 → 문제 → 정답/오답 → 학습 완료
- 우주 맵 명세: 배경 360×1718 반복, 1세트 20문제, 한 화면 6~9개
- 전용 키패드: 분수, ± 입력, 답 칸 추가
- 기본 / 실력 / 도전 3단계

## 부족한 점
1. 게임이 '포장'뿐: 문제 화면은 일반 문제집과 같음 (내재적 통합 부족)
2. 보상과 성장 없음, 주인공 캐릭터 없음
3. 통과 규칙 "10문제 연속 정답" + 제한 시간이 저학년에게 가혹함
4. 오답 시 '다시 풀기'만 있고 힌트나 풀이 없음
5. 스타일이 게임풍 / 일반 앱풍 / 다른 메인 세 가지로 섞임
6. 대상 학년이 불분명 (중학교, 함수 문제 포함)
7. 휴대폰 / 태블릿 대응 없음 (9:16 고정)
8. 저학년에게 글자와 버튼이 작음
9. 로그인이 첫 화면, 만 14세 미만 보호자 동의 절차 없음
10. 일시정지, 나가기 확인, 오류, 튜토리얼, 보호자 화면 없음
