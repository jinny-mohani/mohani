# 렛츠 연산 — 규칙·보상 구조 요약 (새 게임 참고용)

- 대상: 매쓰홀릭에서 운영 중인 초등 연산 게임 '렛츠 연산'
- 조사일: 2026-11-23. 운영 게임 프론트 코드를 읽고 게임 설계만 요약했다. 사내 코드의 경로·API는 옮기지 않았다.
- 화면과 사용 경험은 `letsyeonsan-ux.md`와 `letsyeonsan-screens.pdf` 참고.
- 숫자는 조사 시점 기준이며 운영 중 바뀔 수 있다.

## 게임 흐름
스테이지 클리어 → 코인 획득 → 코인으로 무한 모드 도전 → 상자에서 꾸미기 아이템 → 오리 꾸미기 → 주간 랭킹 시상대에 내 오리 노출.
화폐가 코인 하나라서 학습(스테이지)과 보상(무한 모드)이 한 줄로 이어진다.

## 콘텐츠 구조
- 학년 → 단원 → 스테이지. 문장제 단원은 제외.
- 스테이지는 단원을 5개씩 번갈아 배치한다 (덧셈 5 → 뺄셈 5 → …). 섞어서 풀게 하는 구조.
- 모드: 보통, 어려움(같은 문제, 시간과 감점만 다름), 무한.
- 해금: 이전 스테이지를 깨야 다음이 열림. 보통과 어려움은 따로 진행.

## 한 판
- 목표 약 23층. 정답이면 1층 오르고, 오답이면 하트 1개를 잃고 층이 내려간다.
  - 보통: 1층 하락. 어려움·무한: 최대 3층 하락.
- 하트 3개. 다 잃으면 보통·어려움은 게임 오버(보상 사라짐), 무한은 기록과 보상 저장.
- 문제당 제한 시간은 학년별로 다르다 (예: 초1 보통 15초, 어려움 7초). 무한 모드는 30·50·100층에서 더 빨라진다 ("SPEED UP").
- **틀린 문제는 목록 맨 뒤에 다시 넣어** 나중에 꼭 다시 풀게 한다.
- 힌트 없음, 별점 없음 (클리어 여부만).

## 답 입력
- 실제로는 4지선다만 쓴다. 키패드 입력은 없다.
- 오답 보기는 흔한 실수를 흉내 낸다 (곱셈 받아올림 실수, 정답 ± 작은 수 등).

## 보상
- 스테이지: 무작위 5개 층에 코인 (보통 3개씩, 어려움 5개씩).
- 무한 모드: 하루 첫 판 무료, 이후 코인 50. 정해진 3개 층에 상자, 상자에서 아직 없는 꾸미기 아이템이 나옴. 하루에 얻는 아이템 수를 제한한다.
- 꾸미기 아이템 140개, 6부위 (모자, 안경, 넥타이, 옷, 신발, 손 물건). 무한 모드 상자로만 얻는다.
- 주간 랭킹: 1·2·3등 코인 보상. 이름은 '형용사 + 동물' 무작위 별명.
- 게스트도 전부 플레이 가능. 랭킹만 가려서 회원가입을 유도한다.
- 광고는 자사 앱 홍보 영상. 첫 판 뒤, 그리고 3판마다.
- 앱 리뷰 요청: 오래 쓴 학생이 클리어를 5번 연속했을 때.
