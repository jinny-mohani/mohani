- 대상: `mathplay.matholic.com/ysdj` (초등 연산 게임 '렛츠 연산'), 초등 1학년 테스트 계정
- 조사일: 2026-11-23 · 작성: 허진희 (Claude와 직접 플레이하며 정리)
- 범위: **화면 구성 · 그림체 · 연출/피드백 · 사용성 · 화면 크기별 배치**만 다룸. 게임 규칙과 보상 수치는 제외.
- 대상 기기: **태블릿**을 기준으로 함
- 스크린샷: `letsyeonsan-screens.pdf` (이미지를 한 PDF로 합침. 아래 `images/…` 링크는 원본 파일명 표시용)

## 0. 화면 흐름

```
학년 선택 → 메인(스테이지 선택 + 무한 모드 + 꾸미기 + 랭킹 위젯)
   ├─ 스테이지 도전 → 문제 풀이 → 완료 연출 → 코인 획득 → 광고(홀링) → 메인
   ├─ 무한 모드 도전 → 문제 풀이 → 결과 팝업 → 코인 획득 → 보물상자 열기 → 메인
   ├─ 꾸미기 (전체 화면 오버레이)
   └─ My (내 정보 팝업)
```

## 2. 메인 (스테이지 선택 포함)

![메인](images/01-main.jpg)

| 위치 | 요소 |
|---|---|
| 왼쪽 위 | 현재 학년 칩 (예: '초등 1학년') |
| 오른쪽 위 | 코인 잔액, `My` 버튼 |
| 위쪽 줄 왼쪽 | **내 오리** 카드: 지금 꾸민 오리와 주황 `꾸미기` 버튼 |
| 위쪽 줄 가운데 | **렛츠 무한 연산** 카드: 내 최고 점수(층), `도전하기` 버튼(하루 1회 무료 표시 → 이후 코인 표시) |
| 위쪽 줄 오른쪽 | **주간 랭킹** 위젯: 1~3위 오리가 시상대에 서 있고, 옆에 작게 '내 랭킹'(층·순위) |
| 아래쪽 | **렛츠 연산** 나무판: 스테이지 카드가 5열로 배치, 오른쪽 위에 `보통 / 어려움` 토글 |

스테이지 카드 상태:
- **완료**: 초록 카드에 엄지척 오리와 '완료' 뱃지
- **현재 도전 가능**: 연두 카드에 흰 `도전하기` 버튼 (어려움 모드는 주황 카드)
- **잠김**: 갈색 카드에 회색 자물쇠
- 카드마다 번호와 연산 종류(덧셈·뺄셈)가 적혀 있어요.

## 3. 문제 풀이

![문제 풀이 시작](images/10-play-start.jpg)

- **왼쪽 약 60%: 게임 영역**
  - 지그재그로 쌓인 떠 있는 풀밭 발판마다 '○층'이 적혀 있고, 오리가 그 위에 서 있어요.
  - 코인은 몇 층마다 하나씩 놓여 있어요.
- **오른쪽 약 40%: 문제 패널**
  - 크림색 카드 안에 '다음을 계산하세요.'와 수식(세로셈 또는 가로셈)이 있어요.
  - 그 아래에 큰 흰색 보기 버튼 4개가 세로로 있어요.
- **위쪽**
  - 왼쪽: 노란 뒤로가기 버튼과 '렛츠 연산!' 제목
  - 가운데: 하트 3개와 시간 막대(남은 시간을 숫자로도 표시)
- 무한 모드에서는 왼쪽에 **세로 진행 게이지**(상자 아이콘)가 추가되고, 시간이 더 짧아요.

## 4. 정답 / 오답 / 시간 초과

| 상황 | 연출 |
|---|---|
| 정답 | 고른 보기가 연초록으로 바뀌고 **큰 초록 O**가 떠요. 오리가 다음 층으로 점프하고 카메라가 따라 올라가요. |
| 오답 | 고른 보기가 분홍으로 바뀌고 **큰 빨간 X**가 떠요. 하트 1개가 회색 깨진 하트로 바뀌고, 오리가 **떨어져요**(스테이지는 1층으로, 무한 모드는 3층 아래로). |
| 시간 초과 | 하트가 1개 줄고 한 층 떨어진 뒤, **같은 문제가 다시** 나와요. |

- 오답이어도 **정답은 보여주지 않아요.**

## 5. 층 올라가기 · 코인 · 배경 변화

- 오리가 코인이 있는 층에 가까워지면 코인 주위에 **빛줄기와 반짝이**가 생겨요.
- 코인을 먹으면 코인이 **왼쪽 위 칸으로 날아가** 차곡차곡 쌓여요.
- 높이 올라갈수록 배경이 바뀌어서 올라왔다는 느낌을 줘요.
  - 숲(1~5층) → 하늘·구름(약 9~13층) → 보라 언덕(약 15층) → 분홍 숲(약 19층~)
- 문제 형식도 세로셈과 가로셈이 섞여 나와요.
- 스테이지의 목표 지점은 **주황 아치문**이에요(이번 판은 24층). 문이 화면에 들어오면 빛을 뿜어요.

## 6. 스테이지 완료 · 결과

1. 화면 전체가 초록으로 흐려지고, 빛을 뿜는 **문이 열려요.** 큰 오리가 윙크하며 엄지척을 하고, **'Easy 완료!' 주황 리본**이 떠요. 아래에 '터치해서 계속하기'가 나와요.
2. 탭하면 큰 코인과 함께 **'코인 15개 획득'**이 표시돼요.
3. 다시 탭하면 **홀링 광고가 전체 화면**으로 나와요. 3초 카운트다운 후 `Skip` 버튼이 생겨요.
4. 광고가 끝나면 메인으로 돌아가요. **따로 결과 화면은 없어요**(정답 수, 걸린 시간 등이 표시되지 않음).

## 7. 무한 모드 · 보물상자

- 시작 화면은 스테이지와 같아요. 다만 왼쪽에 **세로 진행 게이지**가 있고, 시간이 약 **7초**로 짧아요.
- 문제 범위가 넓어요(1학년인데 74−2, 20+9처럼 두 자리 수도 나옴).
- 약 26층 발판에 **보물상자**가 있어요. 먹으면 왼쪽 위 코인 줄 끝에 상자 아이콘이 붙어요.
- 하트를 모두 잃으면 끝나요.
  - 나무 팻말 팝업에 **'28층 / 내 최고 점수 102층'**이 표시되고, 보라 리본에 **'렛츠 무한 연산 완료!'**가 떠요.
- 그다음 순서:
  1. 코인 획득 화면
  2. **보물상자**가 빛줄기 속에 나오고, 손가락 아이콘이 '눌러 보라'고 알려줘요.
  3. 누르면 하얗게 번쩍이며 열리고, **아이템(보라 우산)이 튀어나와요.** 아이템 이름은 나오지 않아요.
  4. 메인으로 돌아가요. 무한 카드의 '하루 한번 무료'는 사라지고, 랭킹 위젯에 '내 랭킹 28층 6위'가 생겨요.

## 8. 꾸미기

- 전체 화면 오버레이로 열려요.
  - 왼쪽 위: 노란 X 버튼
  - 왼쪽: 밧줄에 매달린 나무 간판 '내 오리 꾸미기', 오리 미리보기(크게), 주황 `저장` 버튼
  - 오른쪽: 나무 액자 안에 **6개 탭**(모자, 안경, 넥타이, 옷, 신발, 손에 드는 물건). 각 탭에 개수 뱃지가 있어요.
  - 아이템은 3열 그리드로 나오고 스크롤할 수 있어요.
- 아이템 상태
  - **갖고 있음**: 노란 테두리
  - **갖고 있지 않음**: 회색으로 흐릿함. 눌러도 반응이 없어요.
  - **선택됨**: 주황 테두리. 고르는 즉시 미리보기에 반영돼요.
- 손에 드는 아이템은 한 개만 가능해요. 우산을 고르면 안고 있던 토끼가 사라져요.
- 받은 아이템은 해당 탭을 스크롤해야 보이고, 'NEW' 표시는 없어요.

## 9. 랭킹 · My

- **랭킹**: 따로 화면이 없고 메인에 있는 위젯이 전부예요(눌러도 반응 없음).
  - 1등 오리는 그루터기 시상대 위 가운데에 서고 스포트라이트를 받아요. 2·3등은 양옆에 서요.
  - 각 오리 아래에 층수와 닉네임이 있어요. 닉네임은 '느긋한 고라니'처럼 랜덤으로 만들어지고, 불러올 때마다 바뀌어요.
- **My**: 초록 테두리 팝업이에요. 오리 프로필, 아이디, `효과음 ON/OFF` 토글, `로그아웃` 버튼이 있어요.

## 10. 그림체 요약

- **색**
  - 바탕: 밝은 연두·초록
  - 판넬: 나무 질감 갈색
  - 주요 버튼: 주황 (`도전하기`, `꾸미기`, `저장`)
  - 강조: 노랑(코인)
  - 피드백: 초록 O, 빨강 X
- **캐릭터(오리)**
  - 하얀 몸, 노란 부리, 동글동글한 2등신이에요. 머리에 새싹이 달려 있어요.
  - 모자·안경·옷·신발·손 아이템이 겹쳐 입혀져요.
  - 엄지척·윙크 포즈로 칭찬을 표현해요.
- **배경**: 떠 있는 풀밭 발판을 쓰고, 높이 올라갈수록 배경 테마가 바뀌어요(숲 → 하늘 → 보라 → 분홍).
- **UI 질감**: 나무 간판, 리본 배너, 두툼한 그림자가 있는 캐주얼 게임 스타일이에요.
- **글자**
  - UI는 둥글고 굵은 고딕체예요.
  - 문제 수식은 수식 글꼴(세리프)이라 UI와 느낌이 달라요.
  - 보기 숫자는 크지만, 랭킹 닉네임과 '내 랭킹' 글씨는 아주 작아요.

## 11. 좋았던 점

- 정답이면 올라가고 오답이면 떨어진다는 규칙을 **설명 없이도 바로 알 수 있어요.**
- 보기가 4개뿐이고 버튼이 커서 저학년도 누르기 쉬워요.
- 높이에 따라 배경이 바뀌어서 '얼마나 올라왔는지'가 눈에 보이고, 동기부여가 돼요.
- 보물상자를 열 때 손가락 아이콘으로 행동을 유도해서 친절해요.
- 내 오리가 메인, 게임, 랭킹에 모두 등장해서 꾸미기를 할 이유가 생겨요.

## 12. 개선 포인트 (초등 저학년 기준 · 새 게임에서 고칠 항목)

1. **1학년 문제에 음수 보기**가 나와요(예: 1−1의 보기에 −1, −2). 배우지 않은 개념이라 헷갈려요.
2. **오답일 때 정답을 보여주지 않아요.** 다시 풀어 볼 기회도 없어서 학습 효과가 약해요.
3. 무한 모드에서 **한 번 틀리면 3층이나 떨어지고, 시간도 약 7초로 짧아서** 저학년이 좌절하기 쉬워요.
4. 스테이지를 깨면 결과 요약 없이 **광고가 바로 나와요.** 광고의 '무료체험 하러가기' 버튼이 커서 아이가 잘못 누를 수 있어요.
5. 갖고 있지 않은 아이템을 눌러도 **아무 반응이 없어요.** '무한 모드 상자에서 얻을 수 있어요' 같은 안내가 필요해요.
6. 꾸미기를 바꾼 뒤 X를 누르면 **확인 없이 바뀐 내용이 사라져요.**
7. 새로 받은 아이템에 **NEW 표시가 없고**, 스크롤해야만 찾을 수 있어요.
8. 무한 모드가 끝난 직후 메인의 **코인 숫자가 바로 바뀌지 않았어요**(다시 들어가니 반영돼 있었음).
9. 랭킹 위젯의 닉네임과 '내 랭킹' **글씨가 너무 작아요.** 위젯을 눌러도 아무 반응이 없어요.
10. 수식 글꼴이 UI 글꼴과 달라서 화면 안에서 혼자 튀어요.

## 13. 화면 크기별 배치 (태블릿 기준)

> 페이지 안에 해당 크기의 미리보기 틀(iframe)을 띄워서 확인했어요. 실제 기기와는 조금 다를 수 있어요.

| 크기 | 결과 |
|---|---|
| PC (약 1340×900) | 기준 레이아웃. 문제없어요. |
| **태블릿 가로 (1180×820)** | PC와 배치가 같고 전체가 조금 작아질 뿐이에요. **잘 맞아요.** |
| **태블릿 세로 (820×1180)** | 메인: 가로 너비가 고정(약 1160px)이라 **오른쪽이 잘려요**(랭킹이 화면 밖으로 나감). 문제 풀이: **문제 패널과 보기 버튼이 반쯤 잘리고**, 시간 막대가 하트와 겹쳐요. 플레이하기 어려운 수준이에요. |
| 휴대폰 세로 (390×844) | 태블릿 세로와 같은 문제로 화면이 잘려요. |
