## 1. 한 줄 콘셉트
렛츠 연산의 오리가 정답을 맞힐 때마다 하늘로 날아오르고, 공부를 많이 해서 우주선을 받으면 우주로 나가 운석을 부수며 나아가는 6~9살용 픽셀 연산 게임.

## 1-1. 이야기 구조 (v0.3)
| 단계 | 장면 | 정답일 때 | 비고 |
|---|---|---|---|
| 1부 하늘 | 땅 → 구름 → 하늘 끝 | 오리가 날갯짓하며 한 칸 날아오름 | 장애물: 구름, 바람, 새 떼 (확정 전) |
| 우주선 획득 | 하늘 끝 도착 | — | 일정량을 공부하면 받는 큰 보상. 받는 기준은 미정 |
| 2부 우주 | 대기권 → 달 → 소행성대 → 성운 | D안: 레이저로 운석 파괴, 전진 | 7절 D안 스타일 그대로 |

- 근거: 목표가 눈에 보이고 가까워질수록 더 열심히 한다(목표 기울기 효과). 지루해질 즈음 장면이 바뀌면 흥미가 다시 살아난다(새로움 효과).
- 비용: 하늘 장면과 하늘용 문제 연출을 따로 그려야 한다.

## 2. 핵심 고리
비행(문제) → 코인 → 무한 우주(하루 1판 무료, 이후 코인 입장) → 보급 캡슐(꾸미기 아이템) → 꾸미기·랭킹 → 다시 비행.

- 학습이 일어나는 곳은 '비행' 한 칸이다. 나머지는 다시 비행하고 싶게 만드는 장치다.
- 렛츠 연산에서 1년 동안 검증된 구조(문제 → 코인 → 무한 모드 → 상자 → 꾸미기)를 우주로 옮겼다.

## 3. 한 판 규칙
| 항목 | 정한 내용 | 근거 |
|---|---|---|
| 길이 | 10~15문제 | 이 나이의 짧은 집중 시간 |
| 하트 | 3개. 다 잃으면 비행 종료, 모은 코인 절반 유지 | 렛츠 연산의 긴장감은 살리고, 보상을 전부 잃는 좌절은 줄임 |
| 시간 제한 | 보통은 없음, 어려움만 넉넉하게 | 시간 압박은 이 나이에 계산보다 긴장을 먼저 키움 |
| 입력 | 큰 버튼 4지선다. 2~3학년 어려움은 '발사' 키패드 | 손 조작이 서툰 나이 / 스스로 떠올리는 인출 연습 |
| 오답 보기 | 흔한 실수로 만들되 배운 범위 안에서만 (음수 금지) | 렛츠 연산 개선점 |
| 진행감 | 구역별 배경: 대기권 → 달 → 소행성대 → 성운 | 렛츠 연산의 높이별 배경 변화 |

### 틀렸을 때
1. 첫 오답: 그림 힌트와 음성 안내 (예: 7 × 4 → 사과 7개씩 4묶음). 하트는 줄지 않는다.
2. 두 번째 오답: 하트 1개를 잃고, 정답을 보여 준 뒤 다음 문제로. 이 문제는 뒤에 다시 나온다.

## 4. 문제 출제 (자체 생성)
Claude와 함께 출제 규칙(유형, 숫자 범위, 조건)을 설계하고, 게임 프로그램이 그 규칙대로 문제를 만든다. 플레이할 때마다 AI가 문제를 새로 쓰는 방식은 아니다 (틀린 문제, 지연, 비용 문제).

| 무엇을 | 어떻게 | 이유 |
|---|---|---|
| 유형 | 반복한다 | 연산은 반복해야 익숙해짐 |
| 숫자 | 매번 바꾼다 | 답을 외워서 맞히는 일이 없음 |
| 형태 | 빈칸 위치, 그림 세기, 수직선, 거꾸로 묻기를 섞는다 | 지루함은 같은 모양이 계속될 때 커짐 |
| 난이도 | 잘 맞히면 조금 어렵게, 자주 틀리면 쉽게 | 몰입 이론 |
| 틀린 문제 | 조금 뒤에 다시 낸다 | 간격을 둔 반복 |
| 단원 | 섞어서 낸다 | 어떤 방법으로 풀지 스스로 고르는 연습 |

- 범위: 수 세기, 10까지 가르기·모으기, 덧셈·뺄셈(받아올림·받아내림), 구구단.
- 1차 제외: 문장제, 그림 문제(시계, 도형).
- 자동 검증: 정답이 범위 안인지, 보기가 겹치지 않는지, 정답이 보기에 있는지 매 문제 확인.
- 유형 목록은 교육과정 성취기준에 맞추고 콘텐츠 전문가의 확인을 받는다.
- 이유: 회사 문제은행은 중·고등 위주라 6~9살용이 적고, 같은 문제가 반복돼 지루하다는 의견이 있었다.

## 5. 보상
| 보상 | 얻는 법과 쓰임 |
|---|---|
| 코인 | 스테이지 보상. 무한 우주 입장에 사용 |
| 보급 캡슐 | 무한 우주의 정해진 거리마다. 아이템 이름과 NEW 표시 |
| 꾸미기 | 우주복, 헬멧, 우주선. 1차 출시 30개 안팎, 하루 획득 수 제한 |
| 주간 랭킹 | 무작위 별명, 내 순위를 크게, 눌러서 상세 보기 |
| 보호자 리포트 | 맞힌 수, 자주 틀리는 유형 (보호자가 앱을 고르는 나이) |

## 6. 화면과 기기
| 기기 방향 | 배치 | 기준 픽셀 |
|---|---|---|
| 휴대폰·태블릿 세로 | 위: 장면 / 가운데: 문제 모니터 / 아래: 입력 | 폭 180 |
| 태블릿 가로 | 왼쪽 약 55%: 장면 / 오른쪽: 모니터 + 입력 | 높이 240 |

- 정수배 확대만. 비율 차이는 배경을 늘려 흡수.
- 글꼴: 갈무리 12px 하나로 UI와 수식 모두 (렛츠 연산의 수식 글꼴 불일치 해결).
- 버튼 실제 44px 이상.
- 설정: 효과음, 화면 번쩍임·흔들림 끄기 (빛 민감성, 반복 피로).

### 화면 목록 (1차)
학년 선택 · 메인(우주 정거장) · 비행 · 결과(맞힌 수, 코인, 캡슐 → 그다음 홍보) · 꾸미기(NEW, 얻는 법 안내, 나갈 때 저장 확인) · 랭킹 상세 · 설정.

## 7. D안 스타일 요약
- 장면: B 운석 비행. 정답 → 레이저 → 운석 폭발, 충격파, 화면 번쩍임·흔들림, "+10".
- 연속 정답이 쌓일수록 폭발이 커지고 "3연속!" 표시.
- 문제 모니터와 금속 입체 키패드는 A안 모양. 확인 키 이름은 "발사".
- 시안: `../prototype/style-candidates.html` (첫 탭).

## 8. 시작과 계정
- 첫 실행은 로그인 없이 게스트로 바로 비행.
- 첫 스테이지 뒤 "기록 저장하기"로 계정 연결을 권한다.
- 만 14세 미만은 보호자 동의가 필요하다 (개인정보보호법).

## 9. 캐릭터
### v0.3 결정 (2026-11-24)
| 역할 | 캐릭터 | 비고 |
|---|---|---|
| 주인공 | **렛츠 연산의 오리** | 하얀 몸, 노란 부리, 머리의 새싹, 2등신. 픽셀 버전을 새로 그려야 함 |
| 조연 | 꼬마봇 (유지 여부 확인 필요) | 힌트 담당 |

- 고른 이유: 아이들이 이미 아는 회사 캐릭터라 친숙하다. 오리는 날 수 있어 1부 하늘 구조와 잘 맞는다.
- 확인할 것: 렛츠 연산 팀과 캐릭터 사용 협의, 원본 디자인 파일 받기, 렛츠 연산과 계정·꾸미기를 연결할지 (v0.2에서는 별도 프로젝트로 정함).
- 아래 달토끼 내용은 보류한 이전 결정이다.

### v0.2 결정 (보류)
| 역할 | 캐릭터 | 생김새 방향 |
|---|---|---|
| 주인공 | **달토끼** | 머리와 몸이 하나로 이어진 둥근 몸, 짧고 가는 팔다리, 긴 귀 두 개, 작은 점 눈 |
| 조연 | **꼬마봇** | 둥근 네모 머리, 얼굴이 화면 (표정·숫자 표시) |

- 참고 이미지: 단순한 덩어리 몸의 털뭉치 캐릭터들, 팔다리가 짧고 가는 여우 인형.
- 달토끼를 고른 이유: 달에서 방아 찧는 토끼 이야기로 우주와 바로 연결, 긴 귀 덕분에 작은 픽셀에서도 알아보기 쉬움, 회사의 다른 캐릭터(홀링 비버, 렛츠 연산 오리)와 겹치지 않음.
- 꼬마봇 역할(제안): 힌트를 그림으로 얼굴 화면에 보여 주고 음성으로 안내. 글을 잘 못 읽는 6~9살에게 힌트를 전하는 역할.
- 사람 캐릭터는 쓰지 않는다.
