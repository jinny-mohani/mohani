# 업무 진행 기록 (/progress)

평일에 진행 상황을 짧게 말하면, 노션 진행 현황 표에 대신 적는다.
이 표가 금요일 업무일지와 주간업무보고의 **유일한 원본**이다. 다른 곳에 같은 내용을 따로 적게 만들지 않는다.

## 고정 정보

- 진행 현황 표: https://app.notion.com/p/41b9cdd60bf2810a81c6d8c176947d66
  - data source: `collection://41b9cdd6-0bf2-81ac-ad6b-000bef48b7b1`
  - 속성: 업무명(제목) · 상태(기획중/보류/진행중/완료) · 단계(1 기획/2 시안/3 검토/4 개발 전달/5 완료) · 진행(수식, 자동) · 카테고리(UX 개선/디자인 자동화/상시 진행) · 지금 상황 · 다음 할 일 · 시작일 · 목표일 · 마지막 업데이트(자동)
- 사용자: 허진희 (노션 user id `d8ae7cd6-997a-4791-9308-ee68b5dc7ca6`)

## 순서

1. 표의 행을 읽는다(`notion-query-data-sources`, rows 모드).
2. 사용자가 말한 내용을 어느 업무에 넣을지 업무명으로 맞춘다.
   - 애매하면 후보를 보여 주고 묻는다.
   - 새 업무면 새 행을 만든다. 업무명은 `[영역] 내용` 형식으로 쓴다. 카테고리를 모르면 묻는다.
3. 그 행 페이지 본문의 `## 진행 기록` 맨 위(가장 최근이 위)에 오늘 날짜 소제목 `### YYYY-MM-DD`와 불릿을 추가한다. 같은 날짜 소제목이 이미 있으면 그 아래에 불릿만 더한다.
   - 사용자가 말한 사실만 적는다. 추측해서 덧붙이지 않는다.
   - 링크(아티팩트, 피그마, PR)를 받으면 그대로 남긴다.
4. 속성을 갱신한다: `지금 상황`(오늘 내용 한 줄), 필요하면 `다음 할 일`, `단계`, `상태`.
   - 단계가 바뀐 것 같으면 "단계를 2 시안에서 3 검토로 바꿀까요?"처럼 확인하고 바꾼다.
5. 끝나면 한두 줄로 무엇을 적었는지 알려 준다.

## "현황 보여줘"라고 하면

표를 읽어 아래처럼 짧게 보여 준다. 보류는 맨 아래에 둔다.

```
■■□□□ 시안   [AI 서술형] 미리보기 화면 — 미리보기 만드는 중 (다음: 담당자 회의)
■□□□□ 기획   [글잼] 단어장 디자인 가이드 — 가이드 기획 중
```

5일 넘게 갱신이 없는 진행중 업무는 "업데이트가 밀렸어요"라고 표시한다.
