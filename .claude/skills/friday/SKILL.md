# 금요일 정리 (/friday)

원칙: **원본은 진행 현황 표 하나.** 업무일지와 주간업무보고는 그 원본에서 만들어 낸다.
기록에 없는 내용은 지어내지 않는다. 비어 있으면 사용자에게 묻는다.

## 고정 정보

- 사용자: 허진희 (노션 user id `d8ae7cd6-997a-4791-9308-ee68b5dc7ca6`)
- 원본 — 진행 현황 표: https://app.notion.com/p/41b9cdd60bf2810a81c6d8c176947d66 (`collection://41b9cdd6-0bf2-81ac-ad6b-000bef48b7b1`)
  - 각 행 페이지 본문 `## 진행 기록` 아래에 `### YYYY-MM-DD` 날짜별 기록이 있다.
- 업무일지 위치 — '주간 보고' 표: `collection://cbae9743-6b17-4988-b6d4-e2655241f92e`
  - 속성: 업무명(제목) · 작성자(person) · 주차(1~4주차) · 카테고리(상시 진행/디자인 자동화/UX 개선)
- 주간업무보고 링크 표가 있는 페이지: https://app.notion.com/p/4059cdd60bf281b18868f36b88356de5
  - `## 주간 업무보고` 아래 표. 행 = 이름, 열 = `N주차 (M/D~M/D)`
  - **이 페이지는 테스트 기간 10/26~11/20용이다.** 오늘이 이 기간 밖이면 0단계를 따른다.

## 0단계. 위치 확인

1. 오늘 날짜를 확인한다.
2. 위 페이지를 fetch해서 주간 업무보고 표에 이번 주 날짜가 들어간 열이 있는지 본다.
3. 없으면(테스트 종료 등) 노션에서 "주간 업무보고", "주간 보고"로 검색해 새 표 후보를 찾고, **"이 표가 맞나요?"라고 물은 뒤** 진행한다. 확인되면 이 파일의 고정 정보를 새 위치로 고쳐 두자고 제안한다.

## 1단계. 이번 주 재료 모으기

1. 진행 현황 표의 모든 행을 읽는다.
2. 각 행 페이지를 fetch해서 이번 주(월~금) 날짜의 진행 기록을 모은다.
3. 이번 주 기록이 있는 업무만 업무일지 대상이다. 보류이고 기록이 없는 업무는 뺀다.
4. 진행중인데 이번 주 기록이 없는 업무가 있으면 "이번 주에 한 일이 있나요?"라고 한 번에 모아서 묻는다.

## 2단계. 업무일지 쓰기 ('주간 보고' 표, 업무 1개 = 글 1개)

1. 먼저 만들 목록을 보여 주고 확인받는다:
   ```
   4주차 업무일지 4건을 만들게요
   - [AI 서술형 답안입력] 미리보기 화면 (UX 개선)
   - ...
   ```
2. 이미 같은 주차·같은 업무명의 내 글이 있으면 새로 만들지 않고 고칠지 묻는다.
3. 속성: 업무명(진행 현황 표와 같게), 작성자 = 허진희, 주차 = 주간 업무보고 표의 열 기준 주차, 카테고리 = 진행 현황 표 값.
4. 본문은 기존 업무일지 형식을 따른다. 기록이 없는 소제목은 빼거나 짧게 둔다.
   ```
   ## 요약
   (한두 문장)
   ## 작업 내용
   - ...
   ## 결과물
   (링크·이미지. 기록에 있는 것만)
   ## 확인 필요
   - ...
   ## 진행 상태
   - (진행 현황 표의 단계 + 지금 상황)
   ## 다음 작업
   - [ ] ...
   ```
   참고 예시: https://app.notion.com/p/4169cdd60bf280bd9a14fe4a2088cc8e

## 3단계. 대표님 보고용 주간업무보고 (2주치 1개 글)

1. 범위: 지난주 + 이번 주 2주. 두 주의 진행 기록과 업무일지를 재료로 쓴다.
2. 형식은 직전 내 주간업무보고 아티팩트를 따른다. 주간 업무보고 표의 허진희 행에서 가장 최근 링크를 Artifact `read`로 열어 구성을 참고한다.
3. 업무별로 "2주 전 → 지금 어디까지 → 다음"이 보이게 쓴다. 진행 현황 표의 진행 막대(■■□□□)를 함께 보여 주면 좋다.
4. Artifact로 새로 게시하고 링크를 받는다. 게시 전에 artifact-design 스킬을 따른다.

## 4단계. 링크를 표 칸에 넣기

1. 주간 업무보고 표를 다시 fetch한다(칸 위치는 매번 바뀔 수 있으므로 기억한 위치를 쓰지 않는다).
2. 행 = `허진희`, 열 = 제목의 날짜 범위에 오늘이 들어가는 `N주차 (M/D~M/D)`.
3. 그 칸이 비어 있으면 넣을 위치를 먼저 말하고("허진희 × 4주차 칸에 넣을게요") 확인받은 뒤, `notion-update-page`의 `update_content`로 그 행만 바꾼다. 링크 글자는 `주간 업무보고`.
4. 칸이 이미 차 있거나, 맞는 열이 없거나, 허진희 행이 없으면 바꾸지 말고 묻는다.

## 5단계. 마무리

1. 진행 현황 표의 `지금 상황`, `다음 할 일`을 이번 주 기준으로 정리한다.
2. 결과를 짧게 알려 준다: 만든 업무일지 링크들, 주간업무보고 링크, 링크를 넣은 칸.
